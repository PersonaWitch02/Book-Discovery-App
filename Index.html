Project Documentation

OpenShelf: Book Discovery & Reading List Explorer

1. Description & Target User

Built for avid readers, students, and book clubs, OpenShelf is a clean, responsive web application designed to make searching for literature, exploring publication details, and managing a personal reading list fast and friction-free.

2. How to Run

This project is structured with modular vanilla web assets (index.html, style.css, app.js). To run locally:

  1. Download or clone the three files into the same folder.
  2. Open index.html directly in any modern web browser, or serve it via a local static server (e.g., Live Server in VS Code).

3. Data Source Credits

Powered by the public Open Library Search API, a free, unauthenticated REST endpoint providing live book metadata, author details, and cover art thumbnails.

4. AI Assistance Disclosure

AI-assisted development tools were utilized to generate modular starter code, establish Tailwind CSS responsive utility classes, and structure robust asynchronous JavaScript logic for API integration and localStorage state persistence.
