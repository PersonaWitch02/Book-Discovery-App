Project Documentation & README

1. Project Description

OpenShelf is a clean, responsive web application built for avid readers, students, and book clubs. It provides rapid search capabilities, publication details, and a personal reading queue powered by client-side persistence.

2. How to Run

Save the complete code into a single file named index.html (or separate into index.html, style.css, and app.js). Double-click or open the HTML file in any modern web browser. No backend server or authentication keys required!

3. Data Source Credits

This application utilizes the public, unauthenticated Open Library Search API (https://openlibrary.org/developers/api) for live book metadata and cover art thumbnails.

4. AI Assistance Disclosure

This project was developed with assistance from Google Gemini AI to scaffold component architecture, implement robust asynchronous API handlers, and design an accessible, responsive user interface following modern web standards.
